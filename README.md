### Hi, I'm Dennis 👋

Full stack engineer who builds with AI agents, and builds them. Former high school band director.

I build web apps with TypeScript, React, and Node, mostly on Cloudflare Workers these days.

#### How I build

- I write the product, its vocabulary, and the big decisions down in the repo, so agents build to the plan.
- Cheap models do the reading and a stronger model reviews at checkpoints. That's how [ship-kit](https://github.com/denniscampos/ship-kit) works.

- **[ShoutOWT](https://shoutout.epicvibes.xyz)** is a Twitch shoutout overlay for OBS.
